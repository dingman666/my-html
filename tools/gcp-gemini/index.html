GCP / Gemini
用量等级与配额查询指南

整理日期 2026-07-15 · 依据 Google 官方文档 · 政策更新较频繁,使用前建议核对官方链接

先分清两套体系

Google 的 Gemini 模型有两套完全独立的用量体系。你说的 T1 / T2 / T3 属于左边这套(Gemini API);Vertex AI 没有等级概念。

Gemini API(AI Studio 体系)Vertex AI(GCP 企业体系)
API 端点generativelanguage.googleapis.comaiplatform.googleapis.com
认证方式API Key(在 AI Studio 创建)GCP 服务账号 / IAM
用量等级有:Free / Tier 1 / Tier 2 / Tier 3无等级,用动态共享配额(DSQ)
查看位置AI Studio Projects 页面GCP Console 配额页
不确定自己用的是哪套?看代码里请求的域名,或者看认证方式:用 API Key 的是 Gemini API,走 IAM / 服务账号 的是 Vertex AI。

等级定义与升级条件 T1 / T2 / T3

等级升级条件计费上限
Free有活跃项目或免费试用即可—
Tier 1项目绑定一个有效的结算账号(Billing Account)$250
Tier 2累计支付满 $100,且距首次成功付款满 3 天$2,000
Tier 3累计支付满 $1,000,且距首次成功付款满 30 天$20,000 – $100,000+

等级越高,各模型的 RPM(每分钟请求数)、TPM(每分钟 token 数)、RPD(每日请求数)限额越高。各模型的具体数值见官方 Rate limits 文档。

在哪里查看当前等级

用途入口
查看等级标签(最直接) aistudio.google.com/projects
每个项目旁显示 Free / Tier 1 / Tier 2 / Tier 3
查看 API Key(凭据) console.cloud.google.com/apis/credentials
查看等级对应的实际限额数值 console.cloud.google.com/apis/api/generativelanguage.googleapis.com/quotas
注意
  • Console 页面记得在顶部选对项目,或在 URL 后加 ?project=你的项目ID。
  • Console 配额页只显示数值,不显示 Tier 名称;看等级本身要去 AI Studio。

升级机制要点

  • 满足条件后自动升级,无需申请:Free → Tier 1 通常即时生效,更高等级约 10 分钟内生效。
  • 「累计支付」按实际扣款计算——消耗免费试用赠金(如 $300)不计入升级门槛。
  • Tier 3 限额仍不够时,可通过 Rate limits 文档中的申请表单提额,或联系 Google Cloud 销售。

配额机制 无 T1/T2/T3

Vertex AI 不使用 Tier 等级,机制如下:

  • Gemini 2.0 及之后的模型:动态共享配额(Dynamic Shared Quota, DSQ)
    Google 将某模型在某区域的总容量动态分配给所有客户。你的项目没有固定配额数值,不需要也不能申请提额;高峰期可能收到 429,做好重试(指数退避)即可。
  • 更早的模型及 embedding、批量预测等:传统按项目配额,可查看并申请提额。
  • 需要有保障的吞吐量:购买 Provisioned Throughput(预置吞吐量)。

查看方法

Console

console.cloud.google.com/iam-admin/quotas(IAM 和管理 → 配额与系统限制),过滤框输入服务 aiplatform.googleapis.com。传统配额可在行末三点菜单选「修改配额」申请提额。

命令行

gcloud beta quotas info list \
  --service=aiplatform.googleapis.com \
  --project=你的项目ID \
  --format="table(quotaId, metric, dimensions)"

用量监控与告警

通过 Cloud Monitoring 监控配额用量指标,可对接近上限设置告警。
