🌐四个「视角 IP」是什么？为什么会不一样？›
同一台电脑访问不同网站时，出口 IP 可能不同，我们分四个视角展示：
  • 国内视角：访问国内网站/服务器时用的出口 IP（通常走直连线路）。
  • 国际视角：访问未被封锁的国外网站时用的 IP，挂代理时一般显示代理 IP。
  • Google 视角：通过浏览器 WebRTC 向 Google 的 STUN 服务器询问得到的公网 IP，反映真实的网络出口。
  • IPv6：仅当你的网络启用了 IPv6 时才有值，部分网站会优先走它。
若国内 = 国际，通常是直连未走代理；若不同，说明启用了代理或分流规则。
🔀「出口一致性 / 分流」代表什么？›
分流指按规则让不同流量走不同线路——例如国内网站走直连、国外网站走代理，这样又快又省。 所以对代理用户来说，「国内外出口不同」是正常且期望的现象，不是错误。真正需要警惕的是下面的 WebRTC 泄漏。
🛡️代理安全检测怎么看？（WebRTC / 时区 / 语言）›
  • WebRTC 泄漏：浏览器的 WebRTC 功能会绕过 HTTP 代理，直接把你的真实 IP 暴露给网站。若这里显示的 IP 与你的代理出口不一致，说明真实 IP 泄漏了，需要在浏览器或插件里关闭 WebRTC。
  • 时区一致性：你系统的时区应当与代理 IP 所在地的时区吻合，否则网站会觉得"人在美国、时区却在中国"，判定为可疑。
  • 语言一致性：浏览器语言与 IP 归属国常用语言不符，同样是常见的风控信号。
🔎浏览器指纹是什么？会有什么影响？›
网站即使拿不到你的 IP，也能靠"浏览器指纹"识别你是不是同一台设备。做多账号运营时，指纹相同的账号容易被关联封号。
  • Canvas / 音频指纹：用绘图、音频计算出的一串唯一特征值。
  • 显卡 WebGL：暴露你的 GPU 型号。
  • 字体探测：识别你系统装了哪些字体。
指纹越独特，越容易被追踪；要做多账号建议配合指纹浏览器隔离环境。
💎纯净度 / IP 类型 / 风控值（含原生 IP、广播 IP）›
点击检测结果任意一行可看详情与纯净度评分（0–100，越高越像真实用户、越不易触发风控）。评分依据 IP 类型与代理库标记：
  • 住宅 IP / 家宽家庭宽带，最干净；移动网络手机蜂窝，也较干净。
  • 机房 IP / IDC数据中心（AWS、GCP 等），容易被风控。
  • 代理库标记命中了公共代理 / VPN 数据库。
原生 IP：注册国与所在机房/地理位置一致的 IP，通常是家宽或本地 IDC，质量较好。
广播 IP：注册国与实际位置不一致，多为跨国服务商（AWS / GCP / Azure）的 IP，质量一般。
风控值（ping0 口径，与纯净度相反，值越大越危险）分级参考：
<15 极纯净 15–25 纯净 25–40 中性 40–50 轻微风险 50–70 较高风险 >70 极高风险
📡转换时的「连通性」：连通 / 有响应 / 超时›
打开「同时检测连通性」后，会对每个代理端口做一次浏览器直连探测：
  • 连通端口返回了 HTTP 响应，端口在线（http 代理常见）。
  • 有响应端口有反应但未返回 HTTP，socks 代理属正常现象，大概率可用；也可能是连接被拒绝。
  • 超时6 秒内无任何响应，端口大概率不通。
注意：这是浏览器直连端口的活性探测，不等于"通过代理能上网"，实际可用性请以真实使用为准。
⚠️ 仅本地可用：若你从 HTTPS 网站（如 GitHub Pages）打开本页，浏览器会禁止直连 http 端口，连通性会显示「HTTPS 不可测」——把页面下载到本地双击打开即可正常检测。
🛰️如何让在线版（HTTPS）也能测连通性？（部署免费后端）›
HTTPS 页面无法直连端口，需要一个"中转"替浏览器去测。网页照样放 GitHub，无需你自己的服务器。
Cloudflare Worker 不是服务器，是免费的 serverless 云函数，不买机器、不运维，约 2 分钟搞定：
  • 注册 cloudflare.com → 左侧 Workers & Pages → Create → Worker，起个名字部署。
  • 点 Edit code，把项目里 cloudflare-worker.js 的内容整段粘贴进去，Deploy。
  • 复制它给你的地址（形如 https://xxx.workers.dev），填到上方「🛰️ 连通性检测后端」输入框即可。
之后在线版的连通性就是后端真·TCP 握手实测（比浏览器探测更准），结果显示「连通 / 不可达」。
也可用 Node.js 自建（项目里 relay-node.js，含零依赖 TCP 检测与可选的真·代理可用性测试，适合部署到你的 GCP）。
隐私说明：TCP 连通检测只把 IP:端口 发给后端，不含账号密码；只有开启"真·代理测试"才会用到账号密码，且后端是你自己的服务器。
🔒隐私安全 & 常见问题›
  • 账号密码安全吗？转换与检测全部在你本地浏览器完成，账号密码不会上传，只有 IP 地址会用于向公共数据库查询归属地。
  • 为什么某项显示"获取失败"？多为免费数据源临时限流或网络波动，点该处的 ↻ 重试即可，我们已接入多个数据源自动兜底。
  • 检测准不准？归属地与类型来自公共 IP 数据库并做多源交叉，较为可靠；但纯净度/风控为启发式估算，仅供参考，不代表商业风控的真实结果。
